## 三、依赖库选型（不手搓清单）

| 模块 | 选用 | 说明 |
|------|------|------|
| CSV 解析 | commons-csv ≥1.11.1 | 引号内逗号/换行支持；**1.11.0 受 CVE-2025-27820 影响，锁版前 NVD 复核** |
| 编码检测 | juniversalchardet 2.4.0 | Shift_JIS/MS932/UTF-8 检测；**MS932 严格解码（Shift_JIS 会乱 NEC/IBM 扩展字 ①㈱℡≒）** |
| Excel | FastExcel 1.3.0（cn.idev.excel）+ POI ≥5.4.1 兜底 | EasyExcel 已归档之接棒者；**alibaba/easyexcel 勿引入** |
| 扫码 | vue-qrcode-reader 5.7.3 | 内部 BarcodeDetector 优先+ZXing JS 自动降级（Safari 全系无 BarcodeDetector）；jsQR/@zxing/browser 备选构件 |
| 二维码生成 | qrcode 1.5 | 前端 canvas，全站唯一实现 |
| 图片压缩 | browser-image-compression 2.x | Web Worker 压缩 |
| 缩略图 | Thumbnailator 0.4.20 | 服务端 256px 缩略图+重编码剥 EXIF |
| 离线队列 | Dexie 4.4 | IndexedDB 封装；**不用 workbox-background-sync（请求体全量序列化进 IndexedDB，大图不稳）** |
| 状态机 | 手搓五元组边表 | **Spring Statemachine 已进 spring-attic 存档，勿引入**；COLA statemachine 为 LGPL-2.1 无必要 |
| 单号引擎 | FOR UPDATE 计数器（≤100 行自研） | 无成熟「格式化业务单号」库；Leaf/uid-generator 均分布式场景不适用 |
| A4 标签排版 | CSS Grid+mm 单位自研（~200 行） | 无成熟专用库，业界通行做法；qr-code-label-designer（45★ MIT）交互参考 |

## 四、已核验避坑清单

| 项目 | 状态 | 结论 |
|------|------|------|

| Spring Statemachine | 进 spring-attic 存档 | 勿引入 |

| Leaf / uid-generator | 分布式场景 | 单 MySQL FOR UPDATE 计数器足够 |

## 五、日文生态结论

GitHub 无值得借鉴的日文在庫管理 OSS（该市场被 Zaico 等闭源 SaaS 占据）——日文需求落在 i18n/MS932/排版细节，自建是合理结论。雅虎拍卖 CSV 亦无成熟 OSS 处理器（日文生态仅 0-1★ 停更工具），自建映射层（application.yml 配置化）是正解。
